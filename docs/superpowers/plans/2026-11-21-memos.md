# Memos module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Admin and superadmin write or upload official memos (with saved signatories), publish them to employees, and every memo and announcement keeps a history.

**Architecture:** A separate Memos module on the project's usual layers: migrations and models, a `MemoService` (draft, publish, withdraw, restore), a `MemoPdfService` (Blade + Browsershot, frozen copy at publish), a `MemoNotifier`, thin controllers, Inertia pages. One append-only `record_events` table is the history for memos and announcements; announcements become soft-deleted.

**Tech Stack:** Laravel 12, Inertia + React 19 + TypeScript, Tailwind v4, Pest, Spatie permission, Spatie Browsershot (`App\Support\PdfBrowsershot::make()`), Reverb, Wayfinder (generated route files are never edited).

**Spec:** `docs/superpowers/specs/2026-11-21-memos-design.md` (approved 2026-11-21).

## Global Constraints
- Never edit `resources/js/routes/**`, `resources/js/actions/**`, `resources/js/wayfinder/`; Wayfinder regenerates them (the Vite plugin does it while `npm run dev` runs).
- **Ask the user before running `php artisan migrate`** on the dev database. Tests use SQLite in memory and need no permission.
- **Nothing is committed.** The user commits when they say so.
- Roles are enforced on the server (`role:admin|superadmin` route groups plus request `authorize()`), never only in the page.
- Files live on the private disk (`local`, `storage/app/private`) under `memos/...`; never the `public` disk.
- PDFs are built only through `App\Support\PdfBrowsershot::make()`; printed dates use `Asia/Manila`, the app runs in UTC. Headless Chrome does not run in tests: mock `MemoPdfService` where a PDF is needed and test `buildHtml()` directly.
- Limits and formats are enforced on the server and mirrored in the form in the PDS style, with plain-word messages; names reuse `App\Support\PdsRules::personName()`; text boxes use `@/components/limited-input`.
- PHP now allows 12 MB per file, 64 MB per request, 60 files. An uploaded memo is `pdf,jpg,jpeg,png,doc,docx` up to 10 MB; a signature picture is `png,jpg,jpeg` up to 2 MB; a refused upload gets the clear "could not be uploaded" message (pattern: `PdsController::uploadFailedMessage`).
- Tests must not touch real files: all feature tests already run with fake `local` and `public` disks (`tests/Concerns/RefreshesDatabaseWithFakeDisks.php`).
- A published memo never changes. Employees never see a draft or a withdrawn memo or its file. History rows are never edited or deleted.
- Follow the project skills: `architecture-guard` (file placement), `admin-module`, `hrms-authz-check` (run on every new route), `official-form-pdf`, `notify-employee`, and for each new page the `ui-consistency` phases (finding-patterns or adjusting, then a separate check).
- Controllers validate, authorize, call a service, return a response. Pest syntax; helpers go in `tests/Pest.php`.
- Pre-existing failures to ignore: 5 starter-kit auth tests (`EmailVerificationTest` x3, `RegistrationTest` "new users can register", `VerificationNotificationTest`). `npm run types` fails on a tsconfig setting that predates this work; use `node node_modules/typescript/bin/tsc --noEmit --ignoreDeprecations 5.0`.

## Review Focus
Failure modes the spec implies that a plain feature test would miss. Each has a test in the task named.
1. Two memos of the same type published at the same moment must not share a number (Task 9: unique-collision retry).
2. A memo published just after midnight in Manila but still the previous day in UTC belongs to the **Manila** year (Task 9).
3. Editing or deactivating a saved signatory after a memo is published must not change that memo or its frozen PDF (Task 9).
4. A guessed memo id or file URL for a draft or withdrawn memo must answer 404 to an employee, and an unapproved account must be refused (Task 10).
5. Memo text containing HTML or one very long unbroken word must print escaped and wrapped (Task 7).
6. A file PHP refuses (too big) must say so, not fail silently (Tasks 4 and 5).
7. Withdrawing a memo must remove its bell notifications, like deleting an announcement does (Task 9).
